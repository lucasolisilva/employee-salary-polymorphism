# Employee Payment System ☕

Projeto em **Java** desenvolvido para o estudo de **Herança e Polimorfismo** na Programação Orientada a Objetos.

O sistema permite cadastrar funcionários comuns e terceirizados via console e calcular seus pagamentos de acordo com regras específicas para cada tipo de funcionário, utilizando polimorfismo em tempo de execução.

## 🛠️ Tecnologias e Conceitos

-  Java
-  Programação Orientada a Objetos (POO)
- Herança
- Polimorfismo
- Sobrescrita de métodos
- Collections (`ArrayList`)

## 🧠 Como Funciona

O usuário informa a quantidade de funcionários e seus dados.  
Com base no tipo de funcionário (comum ou terceirizado), o sistema calcula o pagamento e exibe o valor final no console.
